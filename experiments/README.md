# experiments/

Finished one-off measurements. Nothing in Bot requires anything from this folder, so it is safe to ignore.
- `YYYY-MM-DD-*.md`: the written results (what was tried, numbers, decision). Newest decisions are summarized in `CLAUDE.md`.
- `*.js`, `*.sh`: the scripts that produced those numbers. Run them from the project root, e.g. `node experiments/answer-e2e.js out.json`.
  They call the real models (they cost quota), and some read sibling files like `router-brief-short.md`.
  They `require("../x")` modules from the project root, so keep them in this folder.
- `hello-claude.js`, `hello-gemini.js`: the first learning steps (Claude CLI and `agy` "hello"); moved here from the root on 2026-11-08, nothing used them.
- `one-thread-results/`, `study-notebooks-files/`: raw data for the matching notes.
- `2026-11-08-wait-for-file.md`, `wait-for-file-live.js`: a course question waits while that course's file is being read (fake models, slow fake reader).
- `2026-11-12-always-up.md`: keeping Bot up (login task + watchdog), what was checked on the laptop and Tailscale, phone steps, and whether Bot can run with the laptop off.
- `progress-history-until-2026-11-12.md`: the old `PROGRESS.md`, every step since day one. It describes files that no longer exist (the front desk, `core.js`, `bot.js`, the switches `BOT_THREAD` / `BOT_BRAIN`); some older scripts here `require` those files and no longer run.
- `window-check.ps1`: proves the watchdog chain opens no window and takes no focus (see `2026-11-12-always-up.md`).
- `2026-11-12-quota-max.md`: where the quota goes (tokens per call, agy overhead, prompt parts) and what was built to stretch it (slim agent, token log, pacing, smaller context). Scripts: `quota-max-measure.js` (free: replays real messages with a fake model), `quota-max-probe.js`, `quota-max-steps.js` and `quota-max-brain-run.js` (these three spend quota).
- `2026-11-15-hydrogen.md`: Gemini 4 Hydrogen (new, same "Gemini Models" pool as Flash) against Argon low and Flash medium in the brain prompt: speed, tokens, math, tool CALL, Hebrew, photo. Script `hydrogen-trial.js` (spends quota, about 21 calls), results `hydrogen-results.json`, made-up photo `hydrogen-photo.png`.
- `2026-11-15-hydrogen-contest.md`: the bigger contest, Hydrogen medium vs high vs Argon low over 25 Bot jobs (math, code, Hebrew, tools, photos, summary and news jobs), with a model-per-job recommendation. Scripts `hydrogen-contest.js` and `hydrogen-contest-round2.js` (spend quota, about 80 calls), results `hydrogen-contest-results.json`, made-up photo `hydrogen-timetable.png`.
- `2026-11-15-hydrogen-round3.md`: the fairer, harder round (Argon medium added, 12 hard tests, the real tutor and reader prompts, 3 repeats, blind grading) and the answers to Omri's two doubts. Scripts `hydrogen-round3.js` (groups hydrogen / argon / blind), `hydrogen-round3-argon-photo.js`, `hydrogen-round3-reveal.js` (spend quota except the last: 204 calls), results `hydrogen-round3-results-*.json`, blind answers, grades and key, made-up PDF `hydrogen-notes.pdf`.
- `2026-11-07-handoff.md`: how the manager chat worked on 2026-11-07 (before the brain); moved here from the root on 2026-11-13. Today the manager keeps its handover note in the shared side-session notes folder.
- `2026-11-13-fable-review.md`: a full review of Bot on 2026-11-13: the ranked list of findings and what was done about each.
- `2026-11-20-neon-deep-trial.md`: the hard Neon trial (13 code-checked tests: hard math, 140k-character reads, coding with hidden tests, a 3-round tool chain with an injected instruction, Hebrew tutoring, the photo) over Neon low..xhigh, Hydrogen, Argon and Claude inside agy, with a verdict per chain and the pool costs. Script `neon-deep.js` (spends quota; `keys`, `table`, `blind` do not), results `neon-deep-results-*.json`, logs `neon-deep-log-*.txt`, blind tutor answers + key.
- `2026-11-20-selfedit-full-access.md`: letting Improve Bot change all of Bot: two holes in today's test gate, real edits with a wide agy editor (Neon medium, Argon low), a scripted red team, a second-reviewer test, and the ranked proposal with the exact new SELF-EDIT rule. Scripts `selfedit-wide-trial.js` (`fence` shows the push fence) and `selfedit-review-trial.js`; prototypes in the root: `selfedit-guard.js`, `health-guard.js` (not used by the running Bot).
