# Bot privacy note

Bot is a personal app that runs on its owner's own computer. It is used by one person only.

- **What it accesses:** the owner's own Google Calendar, with the scope `calendar.events` (read events, add events). It cannot delete or change events.
- **Where data goes:** nowhere else. Calendar data is fetched on the owner's computer and shown to the owner. The Google login token is stored in a local file that is not uploaded or committed.
- **Sharing:** none. No data is sold, shared or used for ads.
- **Revoking:** the owner can remove access at any time at https://myaccount.google.com/permissions.
